title: Configuration
description: Optional configuration for the Expressive Code Color Chips plugin, including how to customize styling.

After adding the Color Chips plugin to your Expressive Code config as shown in [the set-up guide](/expressive-code-color-chips/getting-started/), no further configuration is required.

By default, color chips are added to `css`, `scss`, `sass`, `less`, and `stylus` code blocks. You can enable them for additional languages or customize the appearance of the chips as described below.

## Additional languages

By default, the plugin annotates colors in CSS and CSS-like code blocks. If you use a custom or non-CSS language that includes color values, pass its language tag to the `languages` option to enable color chips for it too.

```js
{
	plugins: [pluginColorChips({ languages: ['metro'] })],
},
```

The languages you provide are added to the built-in CSS dialects, so CSS code blocks continue to display color chips as well.

With the example above, colors are now annotated in `metro` code blocks:

````md
```metro
%%metro line: main | Main | #4CAF50
```
````

## Styling

You can provide custom styles in your Expressive Code config using the `styleOverrides.colorChips` object.

For example, to display square chips instead of the default round style, set `borderRadius` to zero:

```js
{
	plugins: [pluginColorChips()],
	styleOverrides: {
		colorChips: {
			borderRadius: 0,
		},
	},
},
```

## Available style overrides

### `size`

**Default:** `"1.2em"`

The size of each color chip.

### `borderWidth`

**Default:** `"1px"`

The width of the border around each color chip.

### `borderRadius`

**Default:** `"50%"`

The roundness of each color chip.

### `borderColor`

**Default:** `({ theme }) => theme.fg`

The color of the border around each chip.

### `transparencyShadeOne`

**Default:** `["#777", "#fff"]`

The first of two shades used in the checkerboard background for transparent colors.

### `transparencyShadeTwo`

**Default:** `["#000", "#bbb"]`

The second of two shades used in the checkerboard background for transparent colors.
